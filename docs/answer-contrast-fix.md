# Читабельність вибраних відповідей · 17.11.2026

Причину відтворено в браузері: старий `portal-world.css` задавав темний градієнт із `!important`, який перекривав нове світле тло вибраної відповіді. Текст при цьому лишався темним (`rgb(36, 76, 122)`).

Прибрано примусовий пріоритет лише з фону й рамки спільних вибраних відповідей. Поточне оформлення тепер застосовує світле тло `#dcefff` і темний текст `#244c7a`; для вибраної картки — `#e1d4ff` та `#563a91`. Обидві перевірені пари мають контраст понад 4,5:1. Після підтвердження відповіді її текст не приглушується прозорістю.

В інструктажі відновлено виразний стан вибраної відповіді. Оновлено ключ кешування стилів на головній та сторінках класів. Компонування, інша палітра, зміст і логіка уроків не змінювалися.

Через інтерфейс перевірено: вибір безпечної дії, помилку і виправлення, підтвердження результату, вибір картки для сортування, кнопки й органи чуття у «Повідомленнях», відповідь інструктажу. У стилях браузера перевірено фактичний колір, фон без стороннього градієнта і прозорість.
