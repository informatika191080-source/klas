## Педагогічне рішення

Квест «Врятуй цифрову виставку» замість серії тестових запитань. Оля просить урятувати матеріали виставки. Дитина обирає «Космічну пошту» або «Зелену станцію», досліджує матеріал, зберігає зображення, знаходить та впорядковує файл у моделі папок, переносить три речення до чернетки, виправляє авторство й створює власний експонат. Після кожного виконаного доручення є пояснення та явне підтвердження переходу.

Нові навчальні тексти та дві схематичні SVG-ілюстрації створено для порталу, джерела опубліковано в `5/materials/`. Для цих вихідних текстів та зображень явно зазначено CC BY 4.0; ця вказівка не поширюється автоматично на весь портал чи сторонні матеріали. Так відсутня залежність від змісту випадкової «першої новини» зовнішнього сайту.

Справжні завантаження: `image.svg`, готовий `Vystavka.html`, паспорт `Pasport_vystavky.txt`. HTML містить вбудоване зображення й текст, не потребує зовнішніх ресурсів. Назву конкретної папки браузер визначає за своїми налаштуваннями. Модель папок не переміщує справжні файли; це явно пояснено. Окремий фінальний практикум пропонує створити папки на комп’ютері, перемістити й перейменувати справжній SVG, відкрити HTML і показати результат учителю. Портал не заявляє про автоматичну перевірку файлової системи або правильності змісту власного вступу.

Копіювання доступне через звичайні Ctrl+C / Ctrl+V та окремий навчальний буфер. Навчальний буфер позначений окремо від системного. Кнопка «Копіювати» бере лише виділений фрагмент; без виділення дає пояснення. Переказ чужого тексту з клавіатури не змінює авторства.

## Інтеграція й перевірки

Маршрут `5/game.html#download-rescue`. Є картка на мапі, поступ у спільному звіті, резервне копіювання, імпорт і скидання. Збереження попередніх місій не змінювалися. Спільні стилі й канонічні персонажі збережені; новий CSS обмежений робочою областю квесту.

Автотести: обидві тематичні гілки; передумови завантаження, знаходження й організації; збереження розширення; виправлення авторства; екранування експорту; відхилення пошкоджених станів; спільна резервна копія та скидання. Також пройдено всі попередні перевірки `global-network`, `backup`, `messages`, `progression`, `learning-guide`.

Браузер: пройдено космічну гілку від початку до кінця, хибні дії отримують пояснення, правильний крок чекає підтвердження навіть після перезавантаження. Чернетка редактора відновлюється. Справді завантажений SVG прочитано як коректний XML; завантажений HTML повторно відкрито: ілюстрація відображається, зовнішніх ресурсів немає. Власний вступ у тестовій роботі є прикладом для перевірки інтерфейсу.

Публічна перевірка зеленої гілки: виконано всі три доручення, зокрема звичайні Ctrl+C / Ctrl+V без навчального буфера. Редактор відновив введене після перезавантаження. На ширинах 320/390 px горизонтального переповнення немає (видима область/ширина документа 305/305 та 375/375 px зі смугою прокручування). Помічник називає поточну дію та підсвічує відповідний елемент. У фінальній перевірці виправлено відсутній закривний тег навігації, через який блоки на широкому екрані зміщувалися; навігація тепер містить лише три позначки поступу, а робочі блоки розміщені поза нею. Автотести після виправлення пройдено. Апробація з учнями ще не проводилася.
